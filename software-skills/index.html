Unit Contents
Unit I Installing Software (2 Hours)
  1. Introduction to Software and types
  2. Installing of Software (SPSS, MS Office etc.)

Unit II MS Word (4 Hours)
  1. Font and paragraph formatting
  2. Inserting charts, hyperlinks, headers, footer, page number, text box, equations, symbols
  3. Page Margins, orientation, size, indent, spacing, page break
  4. Section break
  5. Mail merge (letters and emails)
  6. Proofing and comments, track changes
Unit III MS Excel (6 Hours)
  1. Sort, Filter, Conditional Formatting, Text to Column, Data Validation, Print titles, Freeze panes
  2. Pivot table/charts
  3. Cell referencing and types
  4. Familiarization with Logical functions, Look up and reference functions, Statistical functions, Math and trigonometric functions, Date and Time functions etc.
  5. Linking work books and worksheets
Unit IV MS Power Point (4 Hours)
  1. Guideline for creating Power Point slides
  2. Slide layout, Font and Paragraph formatting
  3. Inserting table, charts, hyperlinks, slide number, footer, date and time, etc.
  4. Page set up, designs, themes, animations, transitions, set up slide show, rehearse timings, release the current slide
